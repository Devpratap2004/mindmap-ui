# 🧠 MindMap Tree UI

A simple **Mind Map Tree UI** built for **assignment/demo purposes only**.
This project is **not intended for production use** — it is created to demonstrate frontend concepts and interactive visualization.

---

## 🚀 Features

* Interactive mind-map style tree layout
* Built using modern frontend tools
* Clean UI for demonstration
* Easy local setup

---

## 🛠 Tech Stack

* **React + Vite**
* **D3.js** (for visualization)
* **CSS / JavaScript**

---

## 📦 Installation & Setup

Follow these steps to run the project locally.

### Step 1 – Clone Repository

```sh
git clone https://github.com/Devpratap2004/mindmap-ui.git
```

### Step 2 – Move into Project Folder

```sh
cd mindmap-ui
```

### Step 3 – Install Dependencies

```sh
npm install
```

### Step 4 – Run in Development Mode

```sh
npm run dev
```

Your app will be available at:

```
http://localhost:5173
```

---

## 🏗 Build for Production

```sh
npm run build
```

This will generate the optimized production build inside the **dist** folder.
